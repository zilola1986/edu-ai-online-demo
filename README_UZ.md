# EDU AI — internetdagi ochiq demo

Bu tanlov hakamlari uchun xavfsizroq, **alohida demo**. Eski EDU AI v5 loyihasi va uning ma’lumotlar bazasiga tegmaydi.

## 1. Mahalliy tekshirish
`python -m pip install -r requirements.txt`
`python -m streamlit run app.py`

## 2. GitHub
GitHub hisobiga kiring, yangi repository yarating, ushbu papkadagi `app.py`, `question_bank.py`, `question_bank_v2.py`, `edu_ai_background.jpg`, `requirements.txt` fayllarini yuklang. `.db`, parol va haqiqiy o‘quvchi ma’lumotlarini yuklamang.

## 3. Streamlit Community Cloud
https://share.streamlit.io/ ga kiring, GitHub bilan ulang, `Create app` / `Deploy` ni tanlang. Repository va branch `main`, main file `app.py`. Deploy qiling. Berilgan `*.streamlit.app` havolasini tekshiring.

## Muhim
Demo login talab qilmaydi va natijalar faqat brauzer sessiyasida saqlanadi. O‘qituvchi paneli yo‘q; bu xavfsizlik uchun ataylab ajratilgan. Asosiy dastur uchun doimiy baza va xavfsizlik tekshiruvi talab qilinadi.
